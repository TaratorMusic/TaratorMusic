Start sharing on your desktop

  1. On your computer, open TaratorMusic and go to Settings > Phone sync.
  2. Turn sharing off if it is already on.
  3. Copy the webapp address below into the desktop's Webapp address box.
  4. Turn sharing on. Keep the desktop app open.

On this device: connect to your computer

On the computer, copy Desktop address from Phone sync. Paste the whole address here, including https:// and :8443. The faded example above is only a sample.

First time only: trust your computer

Your computer uses a certificate to keep song transfers private. Install it on the device you are using right now. You usually only need to do this once.

Open your computer's certificate page

Before downloading, compare the fingerprint (the long code) on that page with the one in desktop Phone sync. They must match.

    Already installed and trusted this computer's certificate? Go straight to Check connection.

    More help for this device

    When you see Desktop connection is ready, continue to step 3.

    3

    On this device: enter the pairing code

    Find the six-digit code in desktop Settings > Phone sync. Enter it here and press Pair phone. If it expired, press New pairing code on the desktop.

    After pairing, press Transfer test file. When the test succeeds, press Connect and compare below, select music, then press Copy additions and updates. Find your downloaded songs in My Music.
